# Python Basics: Temperature Converter | Python Básico: Conversor de Temperaturas

This repository contains the fourteenth practical exercise from the Programming Language Paradigms course (Digital Games Degree). The goal is to demonstrate the use of basic mathematical operators to convert temperature units in Python using a simple procedural approach.

Este repositório contém o décimo quarto exercício prático da disciplina de Paradigmas de Linguagem de Programação (curso de Jogos Digitais). O objetivo é demonstrar o uso de operadores matemáticos básicos para converter unidades de temperatura em Python usando uma abordagem procedural simples.

## 💻 About the Project | Sobre o Projeto

The script executes sequentially, prompting the user for a temperature in Celsius (°C) via the terminal. It then calculates the equivalent temperature in Fahrenheit (°F) using the standard conversion formula `(C * 9 / 5) + 32`. The result is returned as a formatted string with one decimal place using `f-strings`. It was developed in two versions (English and Brazilian Portuguese).

O script é executado de forma sequencial, pedindo ao usuário uma temperatura em Celsius (°C) via terminal. Em seguida, calcula a temperatura equivalente em Fahrenheit (°F) usando a fórmula de conversão padrão `(C * 9 / 5) + 32`. O resultado é retornado em uma string formatada com uma casa decimal usando `f-strings`. Foi desenvolvido em duas versões (Inglês e Português Brasileiro).
